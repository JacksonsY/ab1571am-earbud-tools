# 给编程 Agent 的提示词

适用于能读取本地仓库和使用开发工具的 Claude Code、Codex，以及其他编程 agent。它们提供任务流程，不会让原本不兼容的设备自动兼容，也不会扩大 agent 的权限。

## 最简单的用法

先在本机克隆并进入仓库，用你的 agent 打开该目录。把下面这段复制给它，将方括号内容替换为实际情况；不知道的信息直接写“未知”。

```text
请先阅读本仓库 AGENTS.md 和 prompts/README.md，再选择与任务匹配的提示词执行。

我的目标：[例如：排查已有弹窗但设备信息 Unknown，或为另一版固件做适配]
设备与固件：[产品/芯片/SDK/构建时间，未知项写未知；不要在这里粘贴真实序列号]
主机系统：[macOS / Windows / Linux 及版本]
已知现象与成功标准：[可观察的现象，以及什么结果才算完成]
已有本地资料：[备份/日志/截图的本地路径，没有则写无]
设备访问授权：[未连接；或仅允许查询这副本人持有/获授权的设备]
硬件写入授权：[无；或引用我在本会话已确认的具体操作及范围]
发布授权：[只做本地修改；或明确的仓库、分支及允许的发布动作]
本地会话目录：work/[不含个人信息的任务代号]/

先从现有文件取得证据，再补问必要信息。完成已授权范围内的工作，不因缺少硬件而停止可独立完成的代码和离线验证。交付时区分事实、推测、未知，以及离线验证和真机验证。
```

建议先用“仅查询 / 无硬件写入 / 只做本地修改”的范围开始。已经在当前会话明确授权过的动作可以引用原授权，无需重新确认；授权必须对应具体设备和操作。

## 按任务选择

| 你现在要做什么 | 提示词 | 完成时应得到什么 |
|---|---|---|
| 第一次使用，或现象还没有定位 | [01 设备识别与只读诊断](01-device-diagnosis.md) | 身份与兼容性结论、两耳证据、最小下一步 |
| 相同家族的新固件/新设备需要适配 | [02 新固件 profile 适配](02-firmware-adaptation.md) | 有证据支撑的最小补丁、拒绝路径测试、支持矩阵 |
| 想迁移到另一主机系统或传输方式 | [03 平台与传输层移植](03-platform-port.md) | 可验证的传输实现、平台限制和离线回放 |
| 代码和变更方案已准备好，需要真机验证 | [04 受控硬件验证](04-controlled-validation.md) | 逐项原值、响应、读回和真实 UI/硬件结果 |
| 准备提交 PR 或发布软件 | [05 评审、脱敏与发布](05-review-and-publish.md) | 审查结果、经过检查的待发布内容及授权范围内的交付 |
| 换一个 agent，或下次继续 | [06 会话交接](06-handoff.md) | 不暴露秘密的本地状态记录，避免重复或盲目重放操作 |

每个文件中的 `text` 代码块都可以直接复制。也可只说“读取 `prompts/02-firmware-adaptation.md`，按其中流程处理我的任务”，再提供该文件需要的输入。不要一次粘贴全部分支；固件适配、平台移植和真机验证是不同任务。

## Claude Code 与 Codex 的入口

- Codex 可从仓库内的 `AGENTS.md` 读取项目约束；启动目录、上层覆盖文件和客户端设置会影响实际加载范围。[OpenAI 官方文档](https://developers.openai.com/codex/guides/agents-md)
- 本仓库的 `CLAUDE.md` 使用 `@AGENTS.md` 引入同一份规则，避免维护两套容易冲突的内容。Claude Code 的具体加载行为以当前版本为准。[Claude Code 官方文档](https://code.claude.com/docs/en/memory)
- 其他 agent 可以通过上方启动提示词显式读取文件。开始时让它简要列出已加载的项目规则；若没有加载，显式要求读取，而不是关闭权限或忽略保护。

这些说明于 2026-10-05 对照官方文档整理。没有在本次文档发布中分别启动 Claude Code 或 Codex 对真实耳机执行整套流程，不能据此声称跨 agent 实机适配已经验证。

## 判断 agent 是否做对了

看到“固件不匹配”，合理的下一步是补充证据或实现隔离的新 profile；不是删除检查。没有真机时，交付离线补丁和明确的待测项；不是宣称设备已修复。只读阶段没有写入清单和授权时，不应出现配置、RAM、重置或升级相关的变更。

公开前，检查的是实际追踪文件和发布包，不能只听 agent 说“已经脱敏”。所有提示词均受[项目规则](../AGENTS.md)及[隐私与法律说明](../docs/PUBLICATION_AND_LEGAL.md)约束。
