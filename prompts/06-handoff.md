# 06 · 会话交接

适合：换用另一种编程 agent、窗口即将结束、设备暂不可用，或下次继续。交接是状态快照，不是自动重放脚本。

```text
请为本任务制作可供另一个 Claude Code、Codex 或编程 agent 继续使用的本地交接记录。先读 AGENTS.md，并核对实际工作区和已有证据。

任务与目标：[填写]
交接位置：work/[任务代号]/HANDOFF.md

记录以下内容：
- 当前目标、用户更正、约束和已有授权；缺失授权明确标记，不能把本记录当作新授权。
- 仓库分支/提交、未提交文件及其用途；区分本任务修改和他人修改。
- 设备/固件范围、两耳可达性、最近验证时间及证据位置；会话结束后连接和角色可能变化。
- 已执行操作和实际结果，分别标注离线测试、真机读回、手机 UI/硬件观察；部分完成的写入单独列出。
- 私有原值与备份的本地路径、恢复依据、未解决问题及已经否定的方案；正文不重复粘贴秘密。
- 下一项最小动作及其前置条件。设备操作必须从重新确认当前状态开始，不能直接重放旧写入。

最后提供一段简短的继续提示词：让接手者先读 AGENTS.md 和该 HANDOFF.md，核对工作区与当前设备状态，再在已有授权范围内继续。若接手者访问不到本地证据，保留未知，不根据旧结论编造原值或宣称成功。

完成标准：交接记录足以区分“做过什么”和“接下来可以做什么”，路径可定位且没有上传私人材料。交接文件保留在被 Git 忽略的位置。
```
